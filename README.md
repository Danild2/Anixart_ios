# Anixart iOS — перенос в разработке

Нативный SwiftUI-клиент по исследованию предоставленного APK Anixart 10.5. Это **незавершённый перенос**. С облачного runner производственный Swift-код проверен на реальных ответах каталога, поиска, релиза и полной цепочки до iframe-видеоссылки. На исходном Windows-компьютере API блокируется HTTP 403 при включённом VPN. Реальный вход, воспроизведение и установка через SideStore пока не подтверждены.

**Unsigned IPA собрана:** [успешный CI 41089213117](https://github.com/Danild2/Anixart_ios/actions/runs/41089213117), [скачать artifact ZIP с IPA](https://github.com/Danild2/Anixart_ios/actions/runs/41089213117/artifacts/12994715735). 15 unit + 3 UI теста прошли; SHA256 и ограничения — [STATUS.md](docs/STATUS.md). Исходники приложения в IPA соответствуют commit `0b337cd7d1511121917c603058c263d5a979d1fc`.

## Что написано

Каталог с реальным API, поиск v2, сортировка/годы/жанры, карточка релиза, коллекции, рекомендации, логин/пароль, Keychain, профиль, избранное, пять статусов, серверная история, чтение/добавление комментариев и оценки. Выбор озвучки/субтитров → источника → серии. Для первой версии выбран внешний VLC: прямой медиапоток передаётся через официальный x-callback URL; для iframe используется обычная страница встраивания Anixart и наблюдение за реально загруженным HTML5-потоком. Страница iframe не выдаётся за медиассылку. HLS-качества читаются из настоящего master playlist. Декодирование реального видео и передача на физическом iPhone ещё требуют проверки.

VLC управляет секундами внешнего просмотра и не возвращает их через этот протокол. Приложение ведёт историю серий; при возврате не подставляет выдуманную позицию. Встроенный AVPlayer/WKWebView оставлен экспериментальным режимом. Его локальные позиции изолированы по аккаунту, озвучке, источнику и серии.

Две темы используют общие экраны: Original с исходными цветами и непрозрачной нижней панелью, Liquid Glass с настоящими системными Tab/TabView. Liquid Glass выбран по умолчанию. Реальный снимок стеклянной панели получен в CI 41092205267; парное сравнение с Android ещё не выполнено. Главная получила девять исходных разделов. Перенесены 2351 UI-строка, 57 массивов и 27 групп plural, но не все экраны уже используют их: это не означает полного переноса приложения.

Лента статей и каналы, друзья, значки, социальный вход, управление аккаунтом, редакторы коллекций, ответы/редактирование/модерация комментариев, уведомления, часть фильтров и настроек, парсеры отдельных видеохостингов. Регистрация по email, восстановление пароля с кодом и расписание написаны, но реальный email-flow/аккаунт ещё не проверен. Индекс найденных функций не выдаётся за их перенос. Иерархия главной и обзора пока восстановлена частично. См. матрицу.

## Сборка на Windows через облако

Workflow `.github/workflows/ios-ipa.yml` использует **xcode-27**, Xcode 27.1 / SDK 27.1. Минимальная iOS — 27.0: установленный runtime 27.1 не принимает iPhone 17, поэтому CI выбирает совместимый runtime и сохраняет фактическую версию в `simulator-coverage.json`. Это не подменяет физическую проверку iPhone 17 с iOS 27.1. Изменение в main запускает проверки; можно запустить вручную на странице Actions → Build and verify iPhone IPA → Run workflow.

Порядок: переносимые проверки → XcodeGen → Xcode analyze → unit/UI tests на совместимом iPhone 17 simulator → Release для iphoneos SDK 27.1 без подписи → ZIP `Payload/AnixartPort.app` → проверка CRC, Bundle ID, ARM64 Mach-O и executable bit → Artifact `AnixartPort-unsigned-IPA`.

После запуска скачать ZIP artifact и извлечь `AnixartPort-unsigned.ipa`. Тестовая IPA выпускается только после успешных core-тестов и сборки. При недоступном провайдере видео artifact может существовать у failed workflow: обязательно прочитать включённый `VALIDATION.json` с отдельными результатами разрешения потока и VLC-декодирования. Такой результат не означает готовность всего порта. Диагностика и `.xcresult` сохраняются отдельно. Проверка упаковки не подтверждает установку на устройстве.

Bundle ID сохранён из starter: `local.anixartport.client`. Не менять при обновлениях. Нет обязательных платных entitlements. SideStore подписывает приложение пользовательским Apple ID; секреты для CI не нужны. Установка поверх той же подписи и идентификатора должна сохранять контейнер, но это необходимо проверить по сценарию. **Не удалять установленное приложение перед обновлением.** После удаления контейнер может быть потерян; Keychain зависит от итогового signing identity/access group.

## Локальная проверка без Mac

```powershell
python tools/check_source.py
python -m unittest discover -s tools -p 'test_*.py' -v
```

Это проверки исходников и упаковщика, а не компиляция Swift. Unit-тесты Swift и UI-тесты выполняются только в CI с iOS SDK.

## Конфиденциальность и ограничения

Пароль отправляется только напрямую одному из двух официальных доменов по HTTPS, не сохраняется и не логируется. Token хранится в Keychain; API Anixart требует query-параметр token, поэтому URLSession использует ephemeral configuration без дискового URL-кэша. Редиректы API на другой host отклоняются. Дисковый каталог записывается только для гостевых запросов; ошибки не заменяются выдуманными данными. Веб-плеер изолирован от токена API и использует непостоянное cookie-хранилище.

Оригинальные APK, декомпиляция, закрытые инфраструктурные параметры, ключи и пароли не включены в репозиторий. UI-тексты перенесены отдельно; восемь SDK/configuration строк исключены. В тестах есть только явно искусственные fixtures. Ни DRM, ни авторизация/защита провайдера не обходятся. Подписанный URL для VLC-проверки сохраняется только в DEBUG-контейнере симулятора и удаляется проверяющим скриптом; в artifacts публикуются лишь счётчики декодирования.
