# Проверки iPhone 17 / iOS 27.1 / SideStore

Пользователь подтвердил воспроизведение Libria в VLC на iPhone. Kodik/Sibnet не работают; остальные сценарии ниже проверяются отдельно. Новую установку не запрашивать до завершения облачных проверок исправлений. Пароль, token, cookies и полный URL с token не отправлять в чат или issue.

## Получение и установка

1. Открыть успешный запуск GitHub Actions, скачать `AnixartPort-unsigned-IPA`, распаковать ZIP. Сверить SHA256 с SHA256SUMS.
2. Подписать и установить IPA в уже настроенном SideStore бесплатным Apple ID. Не включать дополнительные entitlements. Записать точный текст ошибки, если SideStore не принимает IPA.
3. Проверить запуск в портретной/альбомной ориентации, звук при беззвучном режиме. Записать версию iOS, номер сборки и версию SideStore.
4. После входа и сохранения локальной позиции установить следующую IPA **поверх** существующей с тем же Bundle ID и Apple ID. Проверить сохранение сессии, темы и позиции. Не удалять приложение перед обновлением.
5. После очередного продления подписи SideStore проверить те же данные. Проверка семидневного цикла не заменяется единственной установкой.

## Каталог, профиль и состояние

1. VPN оставить включённым по указанию пользователя. В iOS загрузить каталог, прокрутить не менее 10 страниц, вернуться из карточки. Зафиксировать дубли/прыжки/ошибки/рост памяти; недоступность API в текущей сети учитывать отдельно от дефекта клиента.
2. Выполнить быстрые поисковые запросы подряд, очистить строку. Убедиться, что старый ответ не заменяет новый и ввод не зависает.
3. Проверить сортировку, диапазоны лет, пустой результат. Сравнить выдачу Android/iOS с одинаковыми фильтрами.
4. Войти собственными данными. Перезапустить приложение. Проверить профиль. Изменить избранное и статус одного релиза; сверить с Android. Вернуть исходное состояние.
5. Выйти, войти другим аккаунтом при наличии: не должны отображаться чужие списки/секунды просмотра. Проверить ошибку неверного пароля.
6. Прочитать комментарии, раскрыть спойлер. Добавлять тестовый комментарий только там, где это уместно; убедиться, что он не дублируется после сетевой ошибки. Удаление комментария в iOS пока отсутствует.
7. Открыть коллекцию, связанные релизы и рекомендации. Проверить возврат назад и повторный вход в каждую вкладку.

## Видео

Первая версия: установить официальный VLC для iOS, выбрать VLC в настройках Anixart. Пройти озвучка → источник → серия → «Открыть поток в VLC». Для iframe сначала запустить источник обычной кнопкой воспроизведения и дождаться медиассылки. В VLC проверить ≥30 секунд видео и звука, паузу, перемотку, дорожки, качество и поворот. Вернуться в Anixart, открыть следующую/предыдущую серию и проверить соответствие выбранной серии. Повторить без установленного VLC: должно появиться понятное предложение установить его. Проверить источник с истёкшей ссылкой и повторное получение target. Протокол VLC не возвращает секунды; приложение не должно выдавать передачу ссылки за просмотр до конца. Полный подписанный URL не передавать в отчёте.

Пункты о native-позиции ниже относятся к экспериментальному встроенному режиму, который отложен пользователем.

1. Записать release ID, имя озвучки, имя источника и номер серии (без подписанных URL). Проверить несколько типов: прямой HLS, MP4, явно доступный iframe.
2. Запустить серию, смотреть ≥30 секунд; пауза, перемотка назад/вперёд, полный экран, поворот, звук. Проверить доступный выбор качества/субтитров у провайдера; native использует адаптивный HLS.
3. Выйти из native плеера на 90-й секунде и открыть ту же серию/озвучку/источник. Позиция должна восстановиться. Открыть другую серию/источник: позиция не должна наследоваться.
4. Досмотреть до последних 10 секунд; повторное открытие должно начинаться с начала. Сверить серверную историю: она хранит номер серии, не секунды.
5. Отключить сеть во время проигрывания. Проверить понятную ошибку/повтор, отсутствие бесконечных запросов. Источник без iOS-адаптера должен сообщать об ограничении.
6. Для iframe отдельно проверить cookies, fullscreen и возврат. Автоматическое восстановление секунд для iframe не реализовано. DRM/платные/недоступные источники не обходить.
7. Свернуть/вернуть приложение, заблокировать экран, отключить наушники. PiP и фоновое видео не заявлены как поддерживаемые.

## UI, доступность и офлайн

- Для каждого основного экрана снять Android/iPhone кадры с одинаковым контентом: главная, обзор, закладки, профиль, настройки, релиз, комментарии, озвучки, источники, серии, native/iframe плеер. Зафиксировать тему и масштаб шрифта. Без пары кадров визуальное совпадение не подтверждено.
- Проверить Original и Liquid Glass, светлую/тёмную тему, максимальный Dynamic Type, VoiceOver, Reduce Motion/Transparency. Нет перекрытия камеры/Home Indicator и клавиатуры.
- В гостевом режиме загрузить каталог, затем отключить сеть: должен появиться явно датированный сохранённый каталог вместе с ошибкой. Нельзя показывать старый ответ как свежую выдачу поиска.
- Проверить пустую первую установку без сети: реальная ошибка, без демонстрационных релизов.
- Длинная прокрутка: 10+ страниц, наблюдение памяти через доступные инструменты/CI Instruments в дальнейшем. Бюджет памяти пока не измерен.

## Что передать для исправления

Номер CI-сборки/commit, версия iOS, шаги воспроизведения, ожидаемое/фактическое поведение, скриншот без секретов, release ID/серия/источник, текст системной или SideStore-ошибки. Для серверных ошибок достаточно HTTP/application code и времени; полный URL авторизованного запроса не нужен.
