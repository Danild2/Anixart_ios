## Исправления в исходниках

- Обложки: дедупликация загрузок, ImageIO downsampling вне UI, NSCache 32 MB и дисковый кэш 192 MB / семь дней. HTML и повреждённые изображения не кэшируются. Unit-тесты подтверждают один запрос при конкуренции и кэш после пересоздания загрузчика.
- Профиль: исходные цвета пяти списков и круговая диаграмма, дневной график, жанры/аудитории/темы, серии и время в минутах. Общий компонент используется в своём и публичном профиле; приватность статистики учитывается.
- Sibnet: нативный адаптер исходной последовательности HTML → media URL → Referer при первом запросе → подписанные редиректы. Поддерживается указанный сервером HTTPS CDN, не только sibnet.ru. Live playback пока не подтверждён.
- Kodik: настоящая рекламная страница APK и оригинальный callback KodikInterface.advertEnded. Пока реклама активна, её media URL не передаётся в VLC. После настоящего завершения открывается обычная публичная страница плеера. Таймера, поддельного завершения, закрытого partner API или ключей нет.
- CI: отдельные DEBUG captures для трёх источников. Каждый должен дать видео, звук, продвижение времени и длительность эпизода свыше пяти минут. Короткая реклама не считается успехом. Captures удаляются; URL не публикуются. IPA не загружается ни в основной, ни в диагностический artifact при провале обязательной проверки.
- Bundle ID прежний: `local.anixartport.client`. Расширений и дополнительных entitlements нет.

## Оставшиеся требования

Лента/каналы/статьи, друзья, значки, социальный вход, управление аккаунтом, редакторы коллекций, полная модерация комментариев, уведомления, часть фильтров/настроек и адаптеров ещё не перенесены. Индекс 300 API-маршрутов и импорт 2351 UI-строки не означают готовность экранов.

Парное визуальное сравнение Android/iOS, физическая проверка всех источников, поворот/потеря сети, VoiceOver, длительная прокрутка, обновление и продление подписи SideStore остаются отдельными критериями. Секунды просмотра внешний VLC не возвращает; приложение не имитирует их синхронизацию.
